# Bidcairn naming sanity check

Checked on October 29, 2026. Bidcairn combines a bid with a cairn: a visible trail of evidence supporting a decision. The product uses the name consistently in source, interface and documentation.

Exact quoted web searches for `Bidcairn`, `Bidcairn trademark` and `bidcairn.com` returned no indexed result. A GitHub repository-name search returned zero results. These checks found no obvious exact-name conflict; they do not establish legal availability or exclusivity.

The web research tool could not retrieve RDAP, but a subsequent direct HTTPS read of the authoritative Verisign RDAP service succeeded. **bidcairn.com is registered**, with registration event September 17, 2026 and expiration September 17, 2027. It must not be described as available. Domain ownership does not by itself establish a competing trademark, but it is a material naming/discoverability risk. No domain has been purchased. The application can use its hosting-provider subdomain; commercial naming clearance remains pending.

A direct Wordmark search for `Bidcairn` in the official [USPTO search](https://tmsearch.uspto.gov/) returned **No results found**, with both live and dead statuses included. A screenshot is retained locally; the public repository records the textual result. This is an exact-wordmark sanity check, not a similarity clearance.

[TMview](https://www.tmdn.org/tmview/) and relevant Turkish/international registries still require a direct exact/fuzzy class 9/35/42 search before broader commercial publication. Similar-sounding marks and unregistered commercial use are residual risks. Keep full clearance pending in release evidence; do not claim the name is registered, cleared or guaranteed original.
